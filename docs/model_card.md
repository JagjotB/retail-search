# Model card: retail LambdaMART reranker

## Intended use

Rerank a bounded product candidate list for a shopping query. The Amazon ESCI bundle is a public-data demonstration of a generic retail ranking layer. It is not an Amazon production model, an Amazon clone, or a revenue predictor.

## Inputs and outputs

Input candidates contain normalized product text/metadata and a dense retrieval score. The model consumes a fixed ordered schema of semantic similarity, BM25, overlap/exact/phrase/prefix, brand/color/numeric match, description coverage, length, and a MiniLM-L4 cross-encoder score. The cross-encoder starts from a pinned Apache-2.0 MS MARCO revision, is fine-tuned on the project training split only with DCG-normalized ESCI gains, and is exported to OpenVINO FP16. It runs locally from the checksummed promoted bundle; no inference API or network access is required. The reranker returns an unconstrained score, and the API orders candidates descending while reporting both dense and learned values.

## Training data

Official Amazon Shopping Queries ESCI US Task-1 reduced data, with real E/S/C/I query-product judgments. Dataset hashes, measured counts, label distribution, and query-safe split identifiers are generated by the local benchmark and stored in the artifact bundle.

## Evaluation and promotion

The selection metric is validation mean NDCG@10. After selecting the boosting iteration, LambdaMART is refit on train+validation; the cross-encoder remains train-only. Final acceptance is at least 11% relative NDCG@10 improvement over the dense-only baseline on Amazon's frozen test queries. A failed candidate is never promoted. Exact results belong in `artifacts/benchmark.json` and `FINAL_RESULTS.md`, not this static card.

## Limitations and risks

Text and metadata may reproduce catalog bias. The model has no price, availability, margin, click, cart, purchase, or customer-personalization signal. ESCI labels are candidate-list judgments, not exhaustive relevance. Non-US and multilingual behavior is untested. Before a commercial deployment, evaluate retailer-specific relevance, fairness, safety, latency, drift, and online outcomes.
